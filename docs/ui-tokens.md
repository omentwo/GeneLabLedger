# UI token 与图表主题

当前视觉调整沿用原有页面结构与六套主题，将全局样式、仪表盘、台账、快速录入的高频区域收敛到共享变量。

## 层级

- 基础层：`--palette-*` 保存主题色板；`tokens.css` 保存基础分类色、空间和圆角值。
- 语义层：`--app-*` 表示背景、正文、辅助文字、控件边界、状态、图表、焦点等用途。
- 组件层：Element Plus 的 `--el-*` 与页面组件引用语义变量。

控件、卡片、弹窗分别使用 8、12、16px 圆角；胶囊/圆形、无圆角表格和微小拖拽控制点保留形状例外。空间使用 4、8、12、16、24、32px；2px 用于文字/图标的微调。字体、表格尺寸和用户设置的输入尺寸不按间距栅格强制取整。

`--app-control-border` 用于识别输入控件，区别于装饰性的浅分隔线。状态包含文字，重要处沿用 Lucide 图标。用户保存的 Excel 单元格底色属于业务数据，保留原值。

## 图表

`useChartPalette()` 显式依赖共享 `currentTheme`，在主题改变时重新读取 CSS 变量，现有 `DashboardChart` watcher 调用 `setOption()` 更新图表，无需重新查询统计数据。

项目分类色独立于成功、警告、错误色，按项目 ID 得到稳定色槽，排序或筛选不会改变同一项目颜色；图例、项目名称、数值与 ECharts decal 提供颜色之外的信息。柱内标签根据实际柱色选择黑/白文字，避免亮色柱上的白字。

## 验证

自动化逐一检查六主题的正文、辅助文字、导航、主要按钮及状态文字对比度至少 4.5:1；必要控件边界和图表标记至少 3:1；另检查柱内标签及只切换主题时的响应更新。禁用状态、装饰线和用户自定义单元格底色不作为这些固定配对的校验对象。
