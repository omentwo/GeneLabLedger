# 2026-09-05 缺陷核验与修复

本次在现有工作区界面改动之上修复，保留既有主题和样式修改。未修改用户业务数据库，也未制作安装包。

## 高危与中危

| 原问题 | 核验与处理 |
|---|---|
| 1. 跨页底色撤销删除记录 | 存在。记录/单元格底色均从服务端获取全部目标记录的最新快照，校验数量后才提交；清除记录底色明确切换记录模式。 |
| 2. 导入缺列清空核心字段 | 存在。按要求删除 Excel 导入整条链路，消除缺列更新路径。 |
| 3. 粘贴出错清空历史 | 存在。失败刷新保留撤销历史与选择。 |
| 4. 对角填充右上区错误 | 存在。源行右侧按横向序列扩展，下方按纵向序列扩展；文本、数字、日期均有回归用例。 |
| 5. 自动导出保留策略失败与孤儿文件 | 存在。先持久化成功运行，再清理旧文件；待清理路径先持久化，文件占用时保留路径并下次重试，清理失败不重新导出。事务重试复用已经生成的文件。 |
| 6. 导出/导入工作表名不匹配 | 存在于默认选表回退路径。随导入移除；导出保留。 |
| 7. 数值筛选误选文本 | 存在。SQLite 使用严格完整数值解析，非法文本/部分数字/非有限数字返回空值，筛选与数值排序均使用该解析。 |
| 8. 后端连接状态不刷新 | 存在。增加周期健康检查和超时；项目加载失败与后端健康状态分开处理。 |
| 9. 选择建议中间写入/双提交 | 存在。建议项 mousedown 防止失焦触发中间值；选择后的重复 change 被忽略。 |
| 10. Excel 纯时间解析成日期 | 存在。随 Excel 导入解析器移除。 |

## 其他问题

- 空值筛选：`equals ""` 与 `is_empty`、`in [""]` 统一包含 NULL。
- 报告模板创建：初始 flush 纳入异常处理，唯一约束冲突返回 409。
- 导入提交复检、rPh 注音混入文本：相关代码已删除。原提交 Schema 会拦截部分非法状态/日期，但不能替代完整的预览决策复检。
- 自动导出调度器：保存任务引用并回收异常，退出等待在途导出，包括手动触发的运行。
- 旧台账模板：保留原自定义蜡块号字段及其规则，以明确的旧自定义名称避让，再补核心蜡块号字段。
- 打印预览：PDF 和原生预览复用同一数据构建路径；增加 100 工作表、每表 10000 行/200 列、总 200 万格限制。整本台账按项目分别生成工作表；选区按实际输出列区间校验。
- 草稿警告确认后编辑错行：恢复编辑值按记录 ID/字段 ID 定位，草稿保存完成清除旧编辑快照。
- Ctrl+;：统一使用上海日期。
- 实验编排提示：显示本次新增数。
- 自动导出表单：空数值、NaN、空时间在提交前校验；摘要不显示 null；立即执行刷新任务信息但保留未保存表单。
- 报告页面：卸载后停止继续轮询和提示，短暂请求失败允许重试；查询参数选择只消费一次，刷新保留当前选择。
- 审计分页：仅最新请求可更新结果，成功后才更新页码。
- API 客户端：支持外部 AbortSignal 和请求超时，空体/坏 JSON 错误响应统一包装为 ApiError；打印与导出使用较长但有限的超时。
- 日期输入框：showPicker 抛异常时 click 兜底。
- 多窗口布局：服务端比较并交换；冲突时提示并刷新服务端布局，不静默覆盖其他窗口。冲突前排队的旧保存会取消，需要用户在最新布局上重新操作。
- DOCX 同路径：拒绝覆盖模板。
- 自定义值替换：同步维护 ORM relationship 集合，删除使用 delete-orphan。
- 撤销删除时复用旧 position：保留原先明确的排序取舍，未把这一行为改成恢复所有相邻记录的绝对位置。

## Excel 导入移除范围

删除前端按钮、文件选择、预览弹窗、提交逻辑、API 和类型；删除后端路由、Schema 和 XLSX 解析服务；替换导入测试并更新文档。接口返回 404，OpenAPI 不再包含导入接口。Excel 导出、单元格粘贴、报告 DOCX 上传保留。旧审计日志的导入动作标签保留，以便查询历史。
