# 基因检测台账管理系统 — 功能文档

> 本文档描述当前已完成版本的实际行为，面向日常使用、数据维护和故障排查。实现以仓库代码为准，不包含待开发事项。

## 1. 使用范围与入口

系统是 Windows 单机、单用户的基因检测实验室台账工具。Electron 提供桌面窗口和原生文件对话框，Python 后端只监听本机 loopback 地址；业务数据库、模板和导出文件均由用户选择的数据目录保存。当前没有账号、角色、云同步或远程多用户服务。

| 页面 | 路由 | 主要用途 |
|---|---|---|
| 统计面板 | `/dashboard` | 查看项目、状态和月份统计，并导出汇总工作簿 |
| 台账 | `/ledger` | 查询、编辑、导入、导出、锁定和删除记录 |
| 实验编排 | `/experiments` | 选择待实验记录、排序并批量回写实验编号 |
| 自动导出 | `/auto-export` | 配置 XLSX 定时任务、目录、重试、保留和执行历史 |
| 报告模板 | `/reports` | 管理 DOCX 模板版本、占位符映射和直接打印 |
| 日志审计 | `/audit` | 搜索和分页查看数据变更日志 |
| 数据与设置 | `/settings` | 查看或切换业务数据目录 |

首次使用空数据目录时，系统初始化 `TB`、`BRAFV600E` 两个示例项目及其核心字段；已有项目数据不会被重复初始化。

## 2. 项目与表头

- 项目名称必须唯一，可调整顺序和是否参与实验编排；有记录或报告模板的项目不能直接删除。
- 每个项目固定拥有四个核心字段：日期、病理号、实验编号、状态。核心字段不能删除，状态选项固定为“待实验”和“已完成”。
- 可添加文本、数字、日期和下拉选择四种自定义字段，设置显示顺序、宽度、隐藏状态、下拉选项和“新记录默认值”。默认值只预填以后新增的记录，不回写已有记录。
- 隐藏字段不显示在常规台账表格和自动导出工作表中，但不会删除已保存的数据。

## 3. 台账记录

### 3.1 身份和状态

每条记录都有独立 UUID。病理号是可重复的业务字段，不参与记录身份匹配；相同病理号的记录互不覆盖、不联动。实验编号可以为空，也允许在同一项目或不同项目中重复。

记录的关键属性如下：

| 属性 | 行为 |
|---|---|
| 项目 | 记录所属项目；“分配到其他项目”会在目标项目新建一条 UUID 记录，原记录保留 |
| 病理号 | 必填、可重复，可用于搜索 |
| 状态 | 仅允许“待实验/已完成”，由用户手工维护 |
| 实验日期 | 独立的业务日期，可用于统计和批量删除 |
| 实验编号 | 可手工编辑或由实验编排回写，允许重复 |
| 报告状态 | 独立的“已生成/未生成”标记，打印不会自动改变 |
| 锁定 | 锁定后禁止编辑、导入覆盖和删除；解锁本身仍可操作 |

台账支持按项目、状态、实验日期和报告状态筛选，并在病理号、实验编号及自定义字段值中搜索。列表接口默认分页，单页最多 1,000 条。

“快速录入”会打开一个独立的小窗口，而不是占用主台账的抽屉。该窗口默认始终置顶，可自由拉伸，并记住上次的位置和大小；点击“返回主程序”会隐藏快速录入窗口并恢复、聚焦主窗口，再次点击主台账的“快速录入”可回到原窗口和未关闭的内容。

快速录入窗口左侧是当前项目的病理号列表，只显示“未生成报告”的记录；已生成报告的记录不会进入此列表。点击病理号后，右侧可以直接修改所选快捷表头；锁定记录可查看但不能修改。修改提交仍经过台账单元格批量预检，包含字段规则、锁定状态和预期旧值复核，避免覆盖刷新后已经变化的值。

“选择快捷表头”按项目持久保存显示字段和“连续保留”字段。病理号以及配置为必填的字段始终参与快捷录入；新增成功后病理号必定清空，标记为“连续保留”的其他字段继续沿用。新增记录仍执行完整的新记录字段校验，警告需要确认后才会保存。

台账记录保存项目内固定行序。右键任意已保存记录，可在其上方或下方直接插入一行，也可选择插入多行并输入 1–100 的行数；新行先作为本地草稿显示，可以按任意顺序填写各字段，填写病理号后自动保存并保留插入位置。若当前视图启用了字段排序或筛选，保存后的记录仍按该视图规则显示。常规“新增记录”、快速录入、Excel 导入和分配到其他项目默认追加到项目末尾。

### 3.2 Excel 导入

1. 在目标项目选择 `.xlsx` 工作簿和工作表。未指定工作表时优先选择与项目同名的工作表，否则选择第一个可导入工作表。
2. 系统按字段标签、字段 key 或核心字段 system key 识别表头，展示逐行的新增、更新和错误预览。
3. 字段标签不能与其他字段的标签/key/system key 或 `_record_id`、`_project_id` 冲突；历史数据若存在歧义会明确拒绝导入，避免静默映射到错误字段。表头重复、未知表头、病理号为空、日期或状态格式错误、项目 UUID 不一致、记录已锁定等情况也会阻止提交。
4. `_record_id` 命中已有记录时执行更新；为空时新建记录。`_project_id`（如存在）必须与当前项目一致。病理号从不用于匹配。
5. 确认后一次性提交整批数据；UUID、项目归属、锁定状态和字段规则等校验会在提交时再次执行，失败则整批不写入。

导入限制：文件不超过 20 MiB；单个工作表最多 10,000 行、200 列；解压后的 XLSX 总大小不超过 100 MiB，单个内部成员不超过 50 MiB。

### 3.3 Excel 手动导出

导出的每个工作表可以包含系统隐藏列 `_record_id`、`_project_id`，用于之后的精确回导。后端生成 XLSX 字节流，Electron 桌面版通过“另存为”对话框确认文件名、目录和覆盖；浏览器开发模式使用下载链接回退。自动导出任务不使用此保存对话框。

### 3.4 按日期批量删除

1. 选择实验日期、创建时间或更新时间，以及起止日期。
2. 点击“预览”查看总数、锁定数和前 200 条样例。
3. 执行时后端重新计算完整 UUID 集合；集合变化或包含锁定记录都会拒绝执行，要求重新预览或先解锁。
4. 单次预览和执行最多处理 10,000 条记录。

## 4. 实验编号编排

实验编排是当前页面内的临时队列，不是实验状态机，也不产生持久化批次：

1. 从“待实验”记录中选择 UUID 加入队列；已完成记录不会进入候选区。
2. 输入任意前缀，界面按队列顺序预览 `前缀-1`、`前缀-2`……，可按病理号、项目排序或手工上移/下移。
3. 点击“编排完成并回写编号”后，后端在一个事务中再次检查记录存在、未锁定且仍为“待实验”，再写回实验编号。
4. 回写不改变状态、实验日期、锁定和报告状态；前缀和完整实验编号均允许重复。

## 5. 报告模板与直接打印

1. 为项目上传 `.docx` 模板。系统提取 `{{占位符}}`，每次上传生成不可变版本；同一项目的模板名称不能重复。
2. 为每个占位符选择来源：项目字段、固定值、上海当前日期、实验编号、空白或保持未映射。
3. 选择模板版本、最多 100 条记录、打印机和 Word/WPS 引擎（自动、Word 或 WPS）。模板项目必须与记录项目一致，所有占位符必须已映射。
4. 系统在业务数据目录的临时报告目录生成 DOCX，交给 Office 打印后在 `finally` 中清理临时目录；PDF 打印预览默认保留 24 小时，并在启动及生成新预览时清理。界面和 API 不提供报告文档下载接口。

打印成功只记录审计日志，不自动把台账的“报告状态”改为已生成；需要在台账页面单独标记。

## 6. 自动导出

- 任务只支持 XLSX，可选择一个或多个项目，并使用绝对输出目录。目录由 Electron 原生选择框取得，保存任务时会创建目录。
- 周期支持每小时、每天、每周、每月四种预设，或五段 Cron（分钟、小时、日期、月份、星期）。所有执行时间按 `Asia/Shanghai` 计算。
- 任务支持启用/停用、失败重试、立即执行和执行历史；同一任务同时只能有一个运行实例。
- 运行时由 Python 后端自动命名 `任务名_YYYYMMDD_HHMMSS.xlsx`，按成功文件保留数量删除更旧文件。
- 调度器随 Electron 启动的后端启动，约每 20 秒轮询到期任务。退出应用会停止后端；下次启动会把上次未完成的运行标记为失败，并为启用任务恢复下一次执行时间。
- 删除被任务引用的项目时，相关自动导出任务会保留原配置但自动停用，并清空下次执行时间，等待用户重新选择项目后保存。

## 7. 数据目录、时间和审计

首次启动必须选择业务数据目录。设置页更换目录只原子保存路径，重启后生效，不会搬移、复制或删除旧目录中的数据库和模板；选择空目录会得到一套新数据，重新选择原目录即可切回。备份时至少包含 `ledger.db` 和 `templates/`。

- 报告当前日期、自动导出调度/文件名、统计面板当前日、按创建/更新时间批删的日期边界以及界面显示均使用 `Asia/Shanghai`。
- 数据库中的创建时间、更新时间、审计时间和自动任务时间按 UTC 写入；实验日期是无时区的业务日期。
- 新增、修改、删除、锁定、导入、编号回写、模板、打印、自动导出和设置变更都会写入审计日志。后端每次启动清理超过 365 天的日志，并将总量裁剪到最多 100,000 条；可通过 `GENE_LEDGER_AUDIT_LOG_RETENTION_DAYS`、`GENE_LEDGER_AUDIT_LOG_MAX_ROWS` 调整。

## 8. 当前边界

系统当前面向本机 Windows 桌面工作流：不提供账号权限、多用户并发、云同步、远程 API 或自动数据库迁移。跨机器使用时应由用户自行保证共享目录的稳定连接、备份和访问权限。
