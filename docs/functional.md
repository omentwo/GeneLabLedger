# 基因检测台账管理系统 — 功能说明

## 1. 页面

| 页面 | 路由 | 用途 |
|---|---|---|
| 统计面板 | `/dashboard` | 项目、状态和按台账实验日期的统计与导出 |
| 台账 | `/ledger` | 独立 UUID 记录、导入、导出、锁定和批量删除 |
| 实验编排 | `/experiments` | 自由前缀、顺序编号、回写实验编号、导出 |
| 自动导出 | `/auto-export` | 任务、目录、周期、重试、保留和历史 |
| 报告模板 | `/reports` | DOCX 模板、映射、打印机和直接打印 |
| 日志审计 | `/audit` | 搜索数据变更日志 |
| 数据与设置 | `/settings` | 查看和切换业务数据目录 |

## 2. 台账

### 2.1 记录身份

每次新增记录都产生独立 UUID。病理号可重复，仅作为显示和查询字段；修改一条记录不会修改任何其他相同病理号记录。“分配项目”也会在目标项目新建 UUID。

### 2.2 编辑和状态

- 实验日期、病理号、状态和项目动态字段可编辑。
- 实验编号可以在台账直接修改，也可以由编号编排回写；恢复数据时也可由 Excel 导入。
- “待实验/已完成”仅由用户手工标记。实验编排和打印都不自动改变状态。
- 锁定后不能编辑、导入覆盖或删除。

### 2.3 手动导出

导出工作表在最前面带两个隐藏字段：`_record_id`、`_project_id`。Electron 打开 Windows“另存为”，用户可改文件名和目录并确认覆盖。日期过滤始终使用台账实验日期。

### 2.4 导入

1. 在当前项目点击“导入 Excel”，选择本系统导出的 `.xlsx` 或字段表头兼容的工作簿。
2. 选择工作表并查看预览、创建数、更新数和逐行错误。
3. 有未知/重复表头或任一行错误时不能提交。
4. UUID 命中时更新该记录；UUID 为空时新建。病理号从不参与身份匹配。
5. 确认后整批原子提交。

### 2.5 按日期批量删除

1. 选择实验日期、创建日期或更新日期及起止日。
2. 点击预览，查看总数、锁定数和样例。
3. 锁定记录需先解锁。
4. 确认执行时后端重新比较完整 UUID 集合；期间数据有变化则要求重新预览。

## 3. 实验编号编排

实验编排是页面内临时编号队列，不是实验状态机，也不是日期批次。

1. 从“待实验”记录中选择 UUID 并加入右侧编号队列。
2. 填写任意前缀，例如 `20260801`，按队列顺序显示 `20260801-1`、`20260801-2`……。
3. 可按病理号、项目排序，或手工上移/下移。
4. 点击“编排完成并回写编号”，只把显示编号写到相应台账记录。
5. 可以更换前缀再次回写或随时导出 Excel。
6. 用户完成后回到台账手工标记“已完成”。

同一前缀可以重复使用；只有真正回写时才检查完整实验编号是否占用。已完成记录不会进入候选区，回写前也会再次检查状态和锁定状态。

## 4. 报告模板与打印

1. 上传 DOCX 模板并生成不可变版本。
2. 为 `{{占位符}}` 映射台账字段、固定值、上海当前日期、实验编号或留空。
3. 选择记录、打印机和 Word/WPS 引擎。
4. 点击直接打印。

系统为本次打印创建临时 DOCX，Office 接收打印任务后清理临时目录。界面和 API 都不提供 DOCX/ZIP 下载。

## 5. 自动导出

自动导出与手动导出用途不同：

- 用户只在配置时通过 Electron 原生选择框选输出目录。
- 任务运行时自动命名并直接写入该目录，不弹保存框。
- 支持每小时/每天/每周/每月、五段 Cron、失败重试、启停、立即执行和历史。
- 成功后按保留数量删除更旧的本任务文件。
- 调度由 Electron 启动的 Python 后端执行；关闭整个桌面应用后后端停止，应用关闭期间不会执行任务，任务会在下次启动时恢复。

## 6. 数据与设置

首次启动必须选择业务数据目录。设置页展示当前目录；选择新目录后需重启。系统不会帮用户迁移旧数据库，因此：

- 选择空目录会创建一套新数据；
- 原目录保持不变；
- 重新选择原目录即可切回。

## 7. 时间规则

- 报告“当前日期”、自动导出调度/命名、统计面板当前日和批量删除日期边界均按 `Asia/Shanghai`。
- 数据库审计与创建/更新时间戳保存为 UTC，界面转为上海时间显示。
- 审计日志默认保留 365 天、最多 100,000 条；后端启动时删除过期日志并裁剪超出上限的最旧日志。

## 8. UI

应用壳和新设置页使用 Tailwind CSS；复杂表格与表单仍由 Element Plus 提供。Tailwind 不执行 Preflight，因此现有控件行为和基础样式保持稳定。
