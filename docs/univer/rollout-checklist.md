# Univer 替换上线清单

## 阶段一：准备

- [ ] 锁定数据契约和记录/字段 ID 映射。
- [ ] 新建 `UniverLedgerGrid.vue`，不改动现有后端 API。
- [ ] 确认迁移路径不会调用 `drop_all`、删除 SQLite 文件或创建空数据库。
- [ ] 确认旧数据库、项目、字段、记录、底色和报告模板均可被 Univer 正确读取。
- [ ] 明确 Univer 版本、许可证和 Electron/Vite 打包方式。

## 阶段二：核心交互

- [ ] 单击、拖动、多选和键盘导航不会误触发记录拖选。
- [ ] 复制、粘贴、清空单元格与删除记录行为明确区分。
- [ ] 单元格编辑成功后重新读取服务端值。
- [ ] 锁定记录不可编辑、粘贴覆盖或删除。
- [ ] 底色设置和清除与记录 ID 正确对应。
- [ ] 底色只使用 Univer 原生 Fill color/清除底色能力，并将结果回写 `highlight_color`。
- [ ] 切换项目后不会显示或修改其他项目的数据。

## 阶段三：业务回归

- [ ] 从台账选中记录后可以进入报告打印，并且模板项目匹配。
- [ ] 实验编排排序、上下移动和编号回写结果正确。
- [ ] 手动导出列顺序、隐藏列和数据格式保持不变。
- [ ] 自动导出任务仍按项目和计划执行。
- [ ] 记录删除、审计日志和锁定状态保持正确。

## 阶段四：构建与发布

- [ ] `npm run typecheck`。
- [ ] `npm run test`。
- [ ] `npm run build`。
- [ ] 后端测试和打包脚本通过。
- [ ] Windows Electron 安装包启动、置顶、剪贴板和文件保存冒烟测试通过。
- [ ] 记录回滚方式：恢复上一版 Git 标签或安装包；不清除数据库，也不依赖前端旧功能开关。
