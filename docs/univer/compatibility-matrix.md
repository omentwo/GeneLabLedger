# Univer 兼容性矩阵

| 功能 | 当前实现 | Univer 替换策略 | 首版要求 |
| --- | --- | --- | --- |
| 单元格编辑 | 台账内编辑器 + 记录更新 API | Univer 编辑事件转为同一 API | 通过 |
| 多选单元格 | 当前能力有限 | Univer 区域选择和复制粘贴 | 通过 |
| 记录删除 | 选中记录后逐条删除 | 选区转换为记录 ID 后确认删除 | 通过 |
| 记录锁定 | 前后端均校验 | 锁定范围/禁用编辑，后端继续兜底 | 通过 |
| 底色标记 | 记录 `highlight_color` | 使用 Univer 原生 Fill color / `sheet.command.set-background-color`，颜色值回写后端 | 通过 |
| 实验编排 | 独立编排页 | 首版保留原页面 | 不替换 |
| 实验编号回写 | 批量编号接口 | 继续调用现有接口 | 通过 |
| 报告打印 | DOCX + WPS/Word | 继续使用报告页面和打印服务 | 通过 |
| 手动 Excel 导出 | 后端生成 XLSX | 继续使用现有导出 API | 通过 |
| 自动导出 | 后端调度器 | 与表格组件无关 | 通过 |
| 项目隔离 | `project_id` 关联 | 每个项目独立 workbook | 通过 |
| 当前业务数据库 | 现有 SQLite 数据目录 | 不迁移、不清空、不写入；只复制为测试数据库 | 保持不变 |
| Univer 测试数据库 | 尚未接入 | 独立测试目录或当前数据库只读副本 | 首版建立 |
| 物理分库 | 当前为同一 SQLite 数据目录 | 正式分库另行设计，测试阶段不改生产库 | 暂不支持 |
| Excel 原生导入导出 | 自有导入导出服务 | 不依赖 Univer Pro | 保持现状 |
| 打印工作表 | 现有报告打印 | 暂不使用 Univer Pro 打印 | 保持现状 |

## 迁移和回滚原则

- 迁移直接替换台账表格，不保留前端新旧表格切换开关。
- 现有 SQLite 数据库、记录、项目、字段和报告模板不清除、不重建；迁移只允许增量写入和可回滚的结构变更。
- 本阶段不做数据库迁移；测试只使用独立数据库或只读副本，所有测试写入与当前业务数据库隔离。
- 回滚使用 Git 标签或上一版安装包，不通过运行时 UI 开关回退。
- 任何保存、锁定、复制粘贴或项目隔离问题都必须在发布前修复，不能以旧表格分支作为长期兜底。
