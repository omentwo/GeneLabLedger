# Gene Lab Ledger 后端

## 技术栈

| 分类 | 技术 |
|---|---|
| 运行时 | Python 3.13 |
| Web 框架 | FastAPI、Uvicorn |
| 数据模型 | Pydantic |
| ORM | SQLAlchemy 2 |
| 数据库迁移 | Alembic |
| 数据库 | SQLite |
| Excel 导入导出 | Open XML / XLSX |
| 文档处理 | DOCX / Open XML |
| Windows 打印 | Word/WPS COM |
| 后台任务 | Python asyncio |
| 审计与日志 | Python logging、SQLite |
| 测试与质量 | pytest、HTTPX、Ruff |
| 打包 | Nuitka、PyInstaller（由 GitHub Actions 验证） |
